Measure whether Asian Range Filtered plus London Momentum Tight can survive the published $5K Atlas Access rules and yield positive cash after fees on future prices. The VPS observer reads one pinned Exness demo terminal and journals UTC health, raw candidate signals and ordered bid/ask ticks. The separate native `DecemberAccessDemo` EA is the order path. It places broker demo orders only on the explicitly pinned MT5 demo account. It records the evaluation balance and equity relative to a fresh virtual $5,000.

## VPS verification

Use a separate pinned Git checkout and an isolated output directory. Check the revision, observer process, newest status timestamp and completed tick files. Check the trading loop and watchdog separately because their status refers to the legacy runtime. The read-only observer emits local status and has no Telegram sender. On weekends, an old quote can coexist with a healthy observer heartbeat.

The EA shares the native retained signal code and defaults to the two-strategy mask on XAUUSDm M15. It initializes from a clean account at deployment on November 21 and waits for a fresh gold quote before trading. It checks the exact demo login/server, contract, newest quote clock, closed-profit target, daily and trailing equity losses, inactivity and projected 1:100 margin. It stops entries on a pass, breach or window close. A restart following launch requires state reconciliation before orders can resume. Missing exposed midnight equity and disconnection with an open trade block entries. Open trades retain their attached broker stops after a block or cutoff. Check `UltraCore_December2026_status.csv` in MT5's common files and read native deal history for fills.

## Telegram

The separate `UltraCoreDecemberTelegram` task reads the EA heartbeat and the pinned demo account's MT5 deal history. It reports confirmed entry and exit fills, evaluation status changes, and conditions that block or obscure trading. Status messages are quiet. Fills and trading issues use normal notifications. The amount per fill shows its own profit, commission, swap and fees. All message times are in IST. The task leaves order execution to the EA and reads the existing Telegram configuration without copying credentials.

Run `scripts/start_december_telegram.ps1 -ExpectedLogin <demo-login> -ExpectedServer <demo-server>` from the pinned checkout on the VPS while MT5 is open. The installer checks access to the existing chat. Check `logs/december/telegram-status.json` for the last poll and send errors. The notifier reports the actual evaluation launch while the EA is waiting for the market. The sent ledger in the same directory avoids re-alerting confirmed deals after a restart.

A breached attempt stops accepting entries and records its failure in `UltraCore_AccessNov21_26_attempts.csv`. Existing positions retain their broker stops. During the scheduled window, the EA starts a separate virtual $5,000 attempt on the same verified demo once positions and orders are clear and a fresh quote is available. Each retry starts with fresh risk counters, keeps the original cutoff and leaves the failed result in the audit. Telegram sends a breach message and a separate confirmation after a retry actually starts. [Telegram message formats](TELEGRAM_DEMO_MESSAGES.md)
